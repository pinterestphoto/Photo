🌐 Chrome-এ খুলুন

আপনি Instagram-এর ভিতরের browser ব্যবহার করছেন।

Camera ও location permission ঠিকভাবে কাজ করার জন্য Chrome ব্যবহার করুন।

Instagram-এর ⋮ menu চাপুন → Open in browser নির্বাচন করুন → তারপর Chrome দিয়ে এই link খুলুন।

Continue করলে camera ও location permission চাওয়া হবে। Photo ও location এই lab-এর Supabase database-এ save হবে।
